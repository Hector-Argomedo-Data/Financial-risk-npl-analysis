# 🏦 CMF Banking Risk: Credit Risk & Non-Performing Loans (NPL) Analytics

This repository contains the source code, automation scripts, and technical data journal for the **Financial Risk & Non-Performing Loan Analysis (Chilean CMF)** project.

🌐 **[👉 Back to Full Project Presentation in the Portfolio](https://sites.google.com/view/hector-argomedo-portafolio/en-financial-risk-non-performing-loan-analysis)**

---

### 📂 Repository Structure

- 📝 **[`docs/`](./docs/)**: Contains the technical development data journal (`data_journal.md`) following the P.D.A.R. methodology.
- 📜 **[`scripts/`](./scripts/)**: Contains the Python automation script (`etl_excel_to_csv.py`) for mass extraction and cleaning of 48 Excel files into CSV format.
- 📊 **[`sql/`](./sql/)**: Consolidated Google BigQuery queries and views covering the 12-month historical time series.

---

> **Note:** This project analyzes loan portfolios, delinquency rates, and credit loss provisions in the Chilean banking system utilizing Google Sheets, Python, BigQuery SQL, and Power BI.
