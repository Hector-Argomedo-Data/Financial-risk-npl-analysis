Case Study: Global Crocodylian Biodiversity & Distribution Analysis

1. Executive Summary & Project Objectives

Context: In data analysis, raw datasets often present inconsistencies, structural inefficiencies, and a lack of organization. To achieve uniformity—the process data analysts use to ensure data is organized, readable, and structured efficiently—this project establishes a reproducible data pipeline.

Objective: The primary objective of this project is to centralize, clean, and analyze a global dataset regarding crocodylian species. The analysis aims to identify species distribution across continents and establish metrics of maximum length average worldwide, translating raw rows into an interactive reporting asset for stakeholders.

2. Data Wrangling & Ingestion Pipeline (Power Query)

The ingestion phase was conducted utilizing Power Query to apply strict data manipulation and transformation rules before loading the data into the model:

  • Source Connection: Ingestion of the raw flat file containing global crocodylian records.
  • Data Type Validation: Ensured strict adherence to data types across columns (Text for Categorical fields, Decimal/Whole Numbers for Metrics).
  • Data Uniformity & Cleansing: Standardized text inconsistencies, handled null values appropriately, and validated that each row represents a unique biological entity to prevent artificial data inflation during visual aggregations.

3. Data Modeling & Calculations

To prepare the dataset for accurate visualization, the data model properties were adjusted to ensure logical behavior:

Field / Metric Name Data Type Default Summarization Analytical Purpose
id Whole Number Do Not Summarize (No Resumir) Acts strictly as a unique identifier label. Prevented Power BI from applying automatic mathematical aggregations (Sigma sum).
species_count Implicit Metric Count (Recuento) Executes an evaluation of rows to count the total species distribution per geographic area.
Average Length Explicit Aggregation Average (Promedio) Calculates the mathematical mean of the longitud_max_m field globally.

4. Visual Analytics & Interactive Dashboard Design

The dashboard architecture was designed focusing on user experience (UX) and efficient stakeholder data navigation, removing the need for custom querying on the user end:

  • Geographic Bar Chart: Utilizes an interactive column chart mapping species count against continents. Implemented a Conditional Formatting Gradient based on the Count of ID. This visual cue allows stakeholders to instantly detect density variations without reading numbers individually.
  • Interactive Slices (Tile Style / Mosaico): Transformed traditional vertical checkbox lists into modern button tiles. This optimizes real estate and provides a touchscreen-friendly environment for mobile or web stakeholders.

5. Key Analytical Findings & Conclusions

The analysis revealed unexpected distributions in global biodiversity:

  • Americas Leadership: Contrary to common assumptions favoring Africa, the Americas lead in crocodylian biodiversity, hosting a total of 11 distinct species, representing more than a third of global species diversity.
  • Reporting Deliverable: Through the Power BI Service cloud environment, stakeholders can dynamically interact with these findings via an isolated visualization mode—ensuring security over underlying data models while empowering immediate, self-service data exploration.
